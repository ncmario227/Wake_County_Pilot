# Wake_County_Pilot

Title: Pilot for the ASRM web tools in Wake County Government

Description: Provide access, support, and technical consultation on the ASRM web tools for Wake County government.  They are testing the viability and utility of the web tools in an enterprise approach to address management.  There are 15 jurisdictions in Wake County that have various levels of GIS and addressing experience.  This pilot will help test and refine the framework and tooling to implement a shared, enterprise approach to address management.

Wake has broken this pilot into two phases:

Phase 1 is getting one or two town to use the tools and test viability.  
Phase 2 is figuring out the administrative and technical details for establishing an enterprise setup for address management.

Goals 
 
- Determine fitness of web tool in this enterprise approach to address management.
- Iron out the workflow of the address data lifecycle for this use case.
- Obtain feedback and comments on the web tool.
- Figure out the proper backend architecture to enable this use case in production.
- Communicate to towns the value and importance of the MAR in daily operations to get buy-in and adoption.
- Determine the administrative and legal requirements for shared address management and cost sharing.
- Discover opportunities to integrate Wake County’s MAR.
